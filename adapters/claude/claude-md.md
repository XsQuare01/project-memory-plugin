## 프로젝트 메모리 (과제 데이터 저장소)

과제 단위 기억 저장소다. 대화 문맥에 `[프로젝트 메모리] <이름>` 으로 시작하는 글이 들어와 있으면 그 과제가 정해진 것이다.

- 그 과제의 이해·결정·열린 질문·자료는 auto memory 가 아니라 프로젝트 메모리에 기록한다. 규칙은 `<플러그인 폴더>/policy.md`, 명령은 `/project` 스킬.
- auto memory 에는 저장소 함정(reference)만 남긴다. 사용자에 대한 지속 정보(배경·선호·동료 역할)는 사용자 메모리(`pm me`, 로컬 전용)에 기록한다 — 사용자가 직접 말한 지속 정보만, 근거보다 강하게 쓰지 않는다.
- 대화 문맥의 `[사용자 메모리]` 항목은 기본값이다. 지금 요청이 우선하고, 충돌하면 프로젝트 > 회사 > 전역. 사용자 요청 없이 PR·공유 문서에 넣지 않는다. "잊어" 는 `pm me forget`.
- 정본은 직접 고치지 않는다. `pm checkout → 변경안 수정 → pm apply`. 셸로 쓰지 않는다.
- 사용자 확인 없이 confirmed 문서를 바꾸지 않는다. 근거 있는 새 해석은 묻지 않고 별도 proposed 항목으로 기록하고, 응답에 한 줄로 알린다.
- Git 규칙의 예외: 프로젝트 메모리 저장소는 에이전트가 `pm` 쓰기 명령(apply·add-source·new·link·unlink)으로 자기 변경분만 커밋한다. 그 저장소에서도 `git commit` 을 직접 치지 않는다.
- 메모리 쓰기는 메인 세션만 한다. 서브에이전트에게는 읽을 파일 경로만 넘긴다.
- 세션 마무리 신호(끝·다음에·고마워·/clear 전)에는 Notion 기록 제안과 함께 "이번 세션에서 프로젝트 메모리에 남길 것이 있는지" 를 제안한다(`/project save`).
